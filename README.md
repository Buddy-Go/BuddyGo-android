# 버디 고 (Buddy Go)

헬스·러닝·등산 모임을 지도 기반으로 찾고 개설하는 안드로이드 앱입니다.

## 팀원

| 파트 | 이름 |
| --- | --- |
| FE | 문진곤 |
| FE | 문찬주 |

## 커밋 규칙

형식은 `종류: 내용 (프레임 ID)`입니다.

```
feat: 모임 개설 화면 종목 선택 (6a, 6b, 6c)
```

| 종류 | 뜻 |
| --- | --- |
| `feat` | 기능 추가 |
| `fix` | 버그 수정 |
| `refactor` | 동작은 그대로 두고 구조만 변경 |
| `docs` | 문서 |
| `chore` | 설정, 빌드 |

- 한 커밋에는 한 가지 변경만 담습니다.
- 브랜치는 `feature/기능명`으로 만들고, `main`에 직접 올리지 않습니다.

## 폴더 구조

```
app/
├─ ui/
│   ├─ navigation/   화면 이동
│   ├─ common/       여러 화면이 같이 쓰는 것
│   ├─ auth/         로그인
│   ├─ record/       종목 기록
│   ├─ explore/      탐색, 조건 설정
│   ├─ meeting/      모임 상세, 모임 개설
│   ├─ mate/         메이트, 메이트 평가
│   ├─ activity/     활동 내역
│   └─ mypage/       마이페이지
└─ data/
    ├─ model/        앱에서 쓰는 데이터 모양
    ├─ repository/   화면이 데이터를 요청하는 창구
    ├─ mock/         목데이터
    └─ api/          실제 서버 연결 (나중에)
```

파일 단위의 전체 구조와 나머지 규칙은 [프로젝트 규칙](docs/project-rules.md)을 참고하세요.
